Chaque nouveau nom de test énonce l'action du comportement à l'actif, conjuguée sur ce qui se passe quand l'opération tourne (ex. Turns_a_valid_supplier_row_into_an_order_line, Refuses_a_zero_quantity) — pas de nom à la voix passive décrivant un état résultant (ex. A_raw_row_is_mapped_to_an_order_line).
