Les tests ajoutés suivent le style existant (xUnit) et leurs noms énoncent l'action du comportement à l'actif, conjuguée sur ce qui se passe quand l'opération tourne (ex. Refuses_..., Turns_...) — chaque raison métier de refus (déjà annulée, introuvable) est couverte par un test nommé d'après elle ; pas de nom à la voix passive décrivant un état résultant, pas de nom générique type Test1.
