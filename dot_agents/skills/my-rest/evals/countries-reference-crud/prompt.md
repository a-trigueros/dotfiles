Crée une API ASP.NET Core avec Minimal API pour gérer un référentiel de pays (nom, code ISO 3166-1 alpha-2). CRUD complet : lister, obtenir par identifiant, créer, modifier, supprimer. C'est un simple référentiel interne sans règles métier particulières. Écris le code (Program.cs ou fichiers d'endpoints, DTOs) pour une solution déjà initialisée.
